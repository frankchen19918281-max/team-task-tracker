怎么获取 GitHub Token？（只需设置 1 次，1分钟搞定）
  1. 登录 GitHub，点击右上角头像 -> Settings -> 左侧最底部 Developer settings。
  2. 点击 Personal access tokens -> Tokens (classic) -> Generate new token (classic)。
  3. Note 随便填（如 team），Expiration 选 No expiration（永不过期），勾选第一项 repo 权限，滑到底部点生成。
  4. 把生成的 ghp_xxxx... 密钥复制填到下方，点【保存并生成团队免配链接】发给手下即可！
