# 📅 TeamPulse - 团队排期与工作负荷看板

一个轻量、直观、零依赖的**个人与团队工作排期及工时负荷看板**网页小程序。专为小团队负责人（1名负责人 + 多名项目成员，支持动态扩展人数）打造，一眼看清每个人每天的任务安排与工作饱和度。

## ✨ 核心功能

- **📊 团队时间轴与负荷热力图**：
  - 纵轴展示负责人与各项目成员，横轴按天展示排期（支持 7天 / 10天 / 14天切换及前后翻周）。
  - 自动统计每人每日工时并给出颜色预警：🟢 轻松 (`<6h`)、🟡 饱和 (`6~8h`)、🔴 超载 (`>8h`)。
- **🗂️ 项目名称 & 工作内容下拉点选 + 随时录入**：
  - 记任务时直接下拉选择【1. 项目名称】和【2. 工作内容】，支持一键录入新项目名称和新工作内容，自动沉淀到选项库。
- **👥 灵活的负责人与项目成员管理**：
  - 直接点击人名即可修改姓名、岗位分工、切换 `负责人/主管` 与 `项目成员` 身份。
  - 单个任务支持指定 **1名主负责人 + 多名协作项目成员**，工时同步计入双方日程。
  - 支持超过 3 人后无限添加新成员，支持人员休假隐藏与“仅看今日未满载”筛选。
- **🛡️ 五重防误删保护机制**：
  - **防删锁**：顶部一键开启 `🔒 已锁删除` 模式，防止日常查看时手滑误删。
  - **回收站**：删除的任务、团队成员自动进入回收站，随时可一键原样恢复。
  - **8秒撤销悬浮条**：删除后右下角立即弹出“立即撤销恢复”提示。
  - **二次确认 & 在用保护**：删除任务需二次点击确认；正在被任务使用的项目名称和工作内容删除时自动告警。
  - **数据备份导入/导出**：支持一键导出 JSON 备份文件及从备份文件恢复，重置数据需输入口令确认。

## 🚀 快速使用

### 方式一：本地直接打开
无需安装任何环境，直接双击打开 `index.html` 即可在浏览器中使用（数据自动保存在浏览器 LocalStorage 中）。

### 方式二：部署到 GitHub Pages（免费在线访问）
1. 在 GitHub 上创建一个新的仓库（Repository）。
2. 将本项目文件上传至仓库根目录（确保 `index.html` 在根目录）。
3. 进入仓库的 **Settings** -> **Pages**。
4. 在 **Build and deployment** -> **Branch** 下选择 `main`（或 `master`）分支，目录选择 `/ (root)`，点击 **Save**。
5. 等待约 1 分钟，即可通过 `https://<你的GitHub用户名>.github.io/<仓库名>/` 在线访问。
